# บันทึกเงินครอบครัว

เว็บแอปบันทึกฝาก-ถอนเงินของครอบครัว เชื่อมกับ Google Sheet ผ่าน Google Apps Script (GAS) เป็นฐานข้อมูล และ deploy เป็นเว็บ static บน Netlify

หน้าตา: ธีมเข้ม-ทอง หรูหรา, หน้ารวมแสดงยอดทุกกองทุน, กดเข้าไปแต่ละกองทุนจะเห็นปุ่ม **ฝากเงิน** / **ถอนเงิน** แยกชัดเจน พร้อมประวัติรายการและปุ่มแชร์สรุปยอดไปไลน์

## โครงสร้างข้อมูล (ตรงกับ Google Sheet เดิม)

แต่ละกองทุนคือ 1 แท็บ (sheet) ในไฟล์กูเกิลชีทเดียวกัน โดยมีหัวคอลัมน์เหมือนกันทุกแท็บ:

| Timestamp | วันที่ | หมวดหมู่ | จำนวนเงิน | บันทึกเพิ่มเติม |
|---|---|---|---|---|

- **จำนวนเงินเป็นบวก** = รายการฝาก
- **จำนวนเงินเป็นลบ** = รายการถอน

ค่าเริ่มต้นตั้งไว้ 2 กองทุนตามชีทเดิม: `ค่าเทอมลูก` และ `เงินเก็บ` (แก้ไข/เพิ่มกองทุนได้ที่ `config.js`)

## 1) ตั้งค่า Google Apps Script

1. เปิด Google Sheet ของคุณ (ชีทที่มีแท็บ "ค่าเทอมลูก" และ "เงินเก็บ" อยู่แล้ว)
2. เมนู **Extensions > Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทิ้ง แล้ววางโค้ดจากไฟล์ [`gas/Code.gs`](gas/Code.gs) ในโปรเจกต์นี้แทน
4. แก้บรรทัด `const SECRET = "changeme";` ให้เป็นรหัสลับของคุณเอง (ตั้งอะไรก็ได้ที่จำได้ ไม่ต้องซับซ้อน)
5. กด **Deploy > New deployment**
   - Select type: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
6. กด Deploy แล้วอนุญาตสิทธิ์ที่ขอ จะได้ URL ของ Web App มา (ลงท้ายด้วย `/exec`) — คัดลอกเก็บไว้

> ทุกครั้งที่แก้โค้ด `Code.gs` ต้องกด **Deploy > Manage deployments > แก้ไข (ไอคอนดินสอ) > Version: New version > Deploy** ใหม่ URL เดิมจะยังใช้ได้

## 2) ตั้งค่าเว็บแอป

แก้ไฟล์ [`config.js`](config.js):

```js
GAS_URL: "วาง URL จากขั้นตอนที่ 1 ตรงนี้",
APP_SECRET: "ต้องตรงกับ SECRET ใน gas/Code.gs",
```

ปรับรายชื่อ/ไอคอนกองทุนที่ `funds` ได้ตามต้องการ (ไอคอนใช้ชื่อคลาสจาก [Font Awesome](https://fontawesome.com/icons))

## 3) Deploy ขึ้น Netlify ผ่าน GitHub

1. Push โค้ดโปรเจกต์นี้ขึ้น GitHub (repo/branch นี้)
2. เข้า [Netlify](https://app.netlify.com) > **Add new site > Import an existing project**
3. เลือก GitHub แล้วเลือก repository และ branch ที่ต้องการ deploy
4. ตั้งค่า Build:
   - Build command: **เว้นว่างไว้** (ไม่ต้อง build เพราะเป็น static site)
   - Publish directory: `.`
5. กด Deploy — เสร็จแล้วจะได้ URL ของเว็บแอป เช่น `https://your-app.netlify.app`

ทุกครั้งที่ push โค้ดใหม่ขึ้น branch ที่ตั้งไว้ Netlify จะ deploy ให้อัตโนมัติ

## แชร์ไปไลน์

ปุ่ม "แชร์ไปไลน์" ใช้ลิงก์ `https://line.me/R/msg/text/?...` ของ LINE โดยตรง ไม่ต้องสมัคร LINE Developer หรือใส่ค่าอะไรเพิ่ม กดแล้วจะเปิดแอป/เว็บไลน์พร้อมข้อความสรุปยอดให้เลือกส่งได้ทันที

## ความปลอดภัย

เว็บแอปนี้เป็น static site ไม่มีระบบล็อกอิน ใครมีลิงก์เว็บก็เปิดดูข้อมูลได้ (เหมาะกับใช้ในครอบครัว/กลุ่มที่ไว้ใจกัน) ส่วน `APP_SECRET` มีไว้กันไม่ให้คนนอกที่ไม่รู้รหัสยิง API ไปเขียนข้อมูลลงชีทของคุณโดยตรง — อย่า commit รหัสจริงขึ้น public repo หากไม่ต้องการให้คนอื่นเห็น
